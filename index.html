How to Deploy on GitHub & Vercel in 2 Minutes

Zero-Config Ready
Step 1: Push to GitHub
  1. Create a new repository on github.com/new named vikas-inventory-app.
  2. Open terminal in project directory: 
    git init
git add .
git commit -m "Initial TiE inventory suite commit"
git branch -M main
git remote add origin https://github.com/YOUR_USER/vikas-inventory-app.git
git push -u origin main
Step 2: Deploy to Vercel
  1. Open vercel.com/new and select your GitHub repository.
  2. Leave all default settings as is (Framework: Other / Static).
  3. Click Deploy!
  4. Your app will be live globally at:
    https://vikas-inventory-app.vercel.app
